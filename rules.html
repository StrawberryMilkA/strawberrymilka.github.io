📜 奥本海默组织规定

奥本海默组织第五届第四次部长全体会议表决通过
2026年6月3日起实行 · 奥本海默组织保留最终解释权

一、总则

  1. 奥本海默组织是以五大学科竞赛生为主体的综合性学术组织。
  2. 奥本海默组织数学总部是组织的创始总部，代表奥本海默组织开展对外交流活动。
  3. 奥本海默组织必须坚持竞赛生的领导，竞赛生对奥本海默组织拥有绝对领导权。
  4. 奥本海默组织保障成员有序开展各项学术活动，以数学的学术交流为显著特色。
  5. 奥本海默组织拥有对二竞小的领导地位，代表广大二竞小成员的利益。
  6. 奥本海默组织成员依规享有各项权利，同时应积极履行相应的义务。

二、组织架构

  1. 奥本海默组织包含数学总部与其它各部门，数学总部属副组织。数学总部下辖高中数学研究部、高联部、信息学部，均属部级。其他部门包括物理部、地理学部、逻辑学部、综合部，均属部级。（以下“各部门”均代指所有部级部门）
  2. 奥本海默组织各成员层级从高到低依次为：奥本海默组织主席、奥本海默组织数学总部部长、各部门部长、各部门副部长、各部门核心成员、各部门成员。
  3. 奥本海默组织主席拥有绝对权威，负责全组事务的统一管理，属组级干部。
  4. 奥本海默组织数学总部部长负责数学总部下辖部门的统筹管理，属副组级干部。
  5. 各部门部长、副部长负责本部门具体事务的管理，属部级、副部级干部。

三、组织奖励与处分

  1. 组织奖励包括组内表扬、公开表扬、授予勋章等。
  2. 组织处分包括组内批评、公开批评、记过、记大过、留组查看、开除组籍、永久不得加入等。
  3. 组织奖励与处分须由奥本海默组织主席或数学总部部长做出，且原则上需经部长会议投票做出决定。
  4. 组织奖励与处分在奥本海默组织主席与数学总部部长均同意，且部长会议投票通过的情况下，可以撤回。若对自己或其他成员的处分存在疑问，成员拥有申诉的权利。

四、成员权利

  1. 以下条例除第4条外仅适用于各部门核心成员及以上层级。
  2. 奥本海默组织各成员享有参与组织内各项活动的权利。（以下简称“各成员”）
  3. 各成员享有选举权与被选举权。
  4. 各成员对自己与其他成员的处分有申诉的权利。
  5. 各成员享有检举权。

五、成员义务

  1. 各成员应坚持组织的领导、服从组织管理、热爱数学，在组织中不断发展自我。
  2. 各成员应积极维护组织形象，为组织争取荣誉。
  3. 各成员应积极参与组织建设，为组织的发展壮大贡献力量。
  4. 各成员有定期缴纳组费的义务。

六、部长会议

  1. 奥本海默组织于每年3月3日召开奥本海默组织全体大会（以下简称“全体大会”），其余每自然月的3号召开部长全体会议（以下简称“部长会议”）。
  2. 所有成员均有参加全体大会的权利与义务。
  3. 所有副部级及以上干部均有参加部长会议的权利与义务。
  4. 在全体大会与部长会议闭幕期间，有情况需要公开商议的，可经奥本海默组织主席或数学总部部长批准召开紧急部长会议，该会议等同于部长会议。
  5. 组织会议期间，参与会议各成员均有参与讨论、提案、投票、选举、被选举的权利。
  6. 拥有会议与会权的成员，须有二分之一及以上出席会议，本次会议方为有效。

七、加入与退出组织

  1. 欲加入组织者须经组员发展并认真填写《入组申请表》。
  2. 加入组织后，将依据加入者意向和组内情况，决定其加入部门及职位。
  3. 符合以下条件者不得加入组织：
    被处以“永久不得加入”处分者；参与过针对组织敌对活动者；在公开场合发表有损我组织形象言论者。
  4. 欲退出组织的成员须向奥本海默组织主席提出申请，并经部长会议投票决定是否退出。特别地，被给予“永久不得加入”处分者直接自动退出。
  5. 退出组织一个月后，可按流程重新加入组织。
